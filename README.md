# Dystopia · Política de privacidad

Web estática en español para la política de privacidad de Dystopia (`com.datasaints.dystopia`). Sin dependencias, JavaScript, analítica ni fuentes remotas.

## Publicación

GitHub Pages: rama `main`, carpeta `/`.

URL prevista: https://themanzato.github.io/dystopia-privacy/

## Vista previa

Ejecuta `python -m http.server 8088` desde esta carpeta y visita http://localhost:8088.

## Mantenimiento

Edita el texto de `index.html` si cambian la publicidad, las compras, la persistencia o los servicios de la aplicación. Actualiza también la fecha. Los recursos de `assets/` son copias de los recursos originales del proyecto Dystopia y conservan sus derechos originales; no se concede una licencia adicional sobre ellos.

La revisión se basa en el código existente el 23 de noviembre de 2026: guardado AsyncStorage local; AdMob/UMP con anuncios no personalizados; recordatorios locales y consulta horaria HTTPS a Expo; sin cuentas, backend de progreso ni compras integradas de dinero real.

Fuentes: https://developers.google.com/admob/android/privacy/play-data-disclosure y https://support.google.com/googleplay/android-developer/answer/10144311?hl=es.

Esta página pública debe enlazarse en la ficha de Play Console y también desde la aplicación. Publicarla no configura por sí sola los formularios de Play Console ni añade ese enlace al APK.
